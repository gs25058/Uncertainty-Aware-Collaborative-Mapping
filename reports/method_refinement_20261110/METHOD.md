# 경로 완성을 위한 국소 관측 과제 — 방법론 개발 실험

이 실험은 소방관의 **기하학적 진입 경로와 실제 차단을 확인하는 관측**을 개발한다. 온도·가스·구조 안정성에 대한 안전 판정은 하지 않는다. 시작 커밋은 `26f25b3c0758bf76c1e4da25a1dadeefb1b0b383`이다. 기존 결과와 원본은 변경하지 않는다.

## 확인한 병목

학교 scene1, seed0, 무연기, 기존 unknown의 최종 관측 지도에서:

| 관측 지도 내 노드 | 깊이 오차 모델 | 동일 기록 궤적의 이상 깊이 재생 |
|---|---:|---:|
| 지지 증거를 충족한 발판 | 32,219 | 30,933 |
| 발 접촉 조건 충족 | 25,172 | 30,231 |
| 접촉은 충족하지만 몸 공간 미확인 | 10,328 | 13,685 |
| 확인 그래프 노드 | 14,844 | 16,546 |
| 입구에서 연결된 확인 노드 | 3,147 | 11,980 |
| 확인됐지만 입구와 분리된 노드 | 11,697 | 4,566 |

이는 참 지도와의 비교가 아닌 **현재 지도 내부의 증거·연결 상태 진단**이다. 노드 수는 면적이나 도달 목표 수가 아니다. 접촉 산포·최대 hit 높이 거부 건수는 중복될 수 있다. 진단 중 참 형상은 읽지 않았다. 이상 깊이 재생도 목표 20개 중 유효 경로 2개, 상층 유효 경로 0개였으므로 센서 잡음만을 단독 원인으로 볼 수 없다. 이전 stride4→2 재생도 개선하지 못했다.

## 새 관측 가치 v5

`route_tasks.py`는 현재 확인 그래프에서 실제 입구와 연결된 모든 노드를 시작점으로 쓴다. 관측된 지지와 가능성 그래프에서만 잠재 경로를 찾는다. 이 가치 계산 안에서는 연속 미확인 길이 제한을 완화하되 미확인 이동에 비용을 부여한다. **판정 그래프·지도·발판 증거는 변경하지 않는다.**

기존 v4는 미확인 segment 전체의 점군을 질문했다. v5는 선택한 잠재 경로의 미확인 노드와 대각선 이동이 실제로 요구하는 모서리 노드만 질문한다. 이를 세계 좌표의 0.6×0.6×0.3m 구간으로 묶는다. 같은 목표에 대한 여러 구간을 별도 목표로 세지 않는다. 최대 8개 국소 질문과 50,000개 탐색 확장 예산을 사용한다. 잘려서 질문하지 못한 구간도 남은 과제 수에서 제거하지 않는다.

목표에 남은 구간 수를 N, 관측으로 얻을 것으로 예상되는 발판·몸 공간의 공동 증거 개선량 합을 p라 할 때, 경로 완성에 대한 계획 가치는 다음과 같다.

`[1/(1+N-p) - 1/(1+N)] / [1 - 1/(1+N)]`

발판과 몸 공간 예측을 합친 뒤 두 비율의 작은 값을 사용한다. 직렬 구간 하나가 확인돼도 경로 전체가 확인됐다고 간주하지 않는다. 발판만 혹은 몸 공간만 보완하는 관측은 기존 부분 증거 항(0.15)으로 처리한다. 이 식은 **남은 관측 작업에 대한 휴리스틱이며, 유효 경로 확률이 아니다.** 실제 통과 가능 판정과 제시 경로 평가는 기존 코드가 수행한다.

## 모든 방식의 공통 후보

같은 관측 지도·공개 목표 영역·드론 상태를 입력받아 frontier와 국소 경로 보완 후보를 최대 24개 만든다. 새 보완 후보는 관측으로 확인된 비행 가능 공간에서 발판 위 0.85/1.25m, 수평 거리 1.2/2m의 제한된 제안을 검사한다. 최대 128개 제안을 질문별 순환 방식으로 분배한다. 최대 10개의 보완 후보가 기존 후보를 대체한다. 두 방식에 같은 후보 생성 코드와 설정을 제공한다.

후보 가시성은 현재 점유 지도와 같은 카메라 intrinsics·거리·pitch 프로그램으로 예측한다. 관측된 벽을 관통하는 이득은 허용하지 않는다. 미관측 영역 뒤의 가시성은 예측값이다. 후보 생성·점수에는 메시, 참 깊이, 미래 관측, 참 연기 투과율이나 목표 정답을 사용하지 않는다.

## 짝지은 폐루프 비교

초기 탐색 차이와 남은 경로 완성 능력을 구분하기 위해 기존 precision_v4의 **180초 실제 체크포인트**를 각 방식의 동일 시작 상태로 쓴다. 장면 0/1/4/8 × 실행 seed0 × clean/strong × 다음 세 방식 = **24회**, 각 32초 추가 실행이다.

- `unknown_common`: 공통 후보에서 추가 미관측량 기준.
- `precision_common`: 공통 후보에서 기존 v4 가치.
- `repair_common`: 공통 후보에서 새 v5 경로 과제 가치.

전체 OctoMap 확률, SupportSurfaces 통계, hit 최대값, 실제/추정 기체 위치, 실패한 기체, 예약 궤적, 진행 중 촬영 대기, 실제 관측 이력을 그대로 복원한다. 드론을 재배치하거나 실패 기체를 복구하지 않는다. 관측은 복원 시각 다음 tick의 실제 위치·자세에서 생성한다. 이동·촬영·충돌·대기는 추가 시간에 포함한다. 정책별 센서 시드 키는 사용하지 않는다.

주 비교에서 변경되는 것은 관측 가치다. 사람 모델, 센서, 연기, 비행·예약, 추가 시간, 목표·참 형상·분모는 고정한다. 센서는 기존 D455 공개 사양을 참고한 낙관적 깊이 관측 모델이고 실제 화재 검증은 아니다. 4대, perfect_odometry, 320×180 깊이 격자, 4Hz, optical Z 0.6–6m를 유지한다. 몸 높이 1.90/1.40/0.90m, 폭 0.70/0.45m, 한 걸음 0.18m, 발판 최소 실제 2프레임, 발 접촉 offset 0.025m를 유지한다.

이는 **공통 다중 드론 탐색 파이프라인에서 관측 가치 함수 비교**의 후반부 복구 실험이다. 입구에서 새로 출발한 212초 임무, 독립 검증 장면, 또는 새 실행 seed의 성능으로 보고하지 않는다. 이 네 장면은 기존 개발 장면이다. 장면 확장은 비교 결과를 보기 전에 고정했으며 `design_initial.json`과 `design.json`에 이유를 보존했다.

주 시점은 212초의 최종 상태다. 중간 최고 성능으로 대체하지 않는다. 분모는 방식마다 동일한 도달 가능 목표 70개, 차단 목표 74개, 전체 144개다. 오류율은 무효 / (유효+무효) 제안 경로다. 검증 불가 제안은 별도다. 전후 변화는 임무 0초가 아닌 **각 분기의 실제 시작인 180초**와 비교한다. 초기 실패와 새 실패, 총 촬영과 추가 촬영을 분리한다.

## 별도 판정·경로 추출 진단

관측 배정 비교와 섞지 않고 기존 unknown 8개 지도, precision_v4 8개 지도, 4초 연결 시험 지도 1개에서 다음을 재평가한다. 새 촬영이나 이동은 없다.

1. 원래 최단 비용 경로·기존 차단 증명.
2. 같은 확인 그래프에서 발판 산포·관측 수·확인 발판 이웃 폭으로 경로 비용만 변경.
3. 목표의 관측된 발판 일부가 아닌 **허용 도착 영역의 모든 가능성**을 포함한 차단 증명.
4. 2와 3의 결합.

경로 비용 실험은 노드·간선·도달 여부를 바꾸지 않는다. 실제 제시할 경로를 모두 정한 뒤 참 형상을 열어 검증한다. 더 좋은 참 경로를 찾아 대신 제시하지 않는다. 이 비용이 오히려 무효 경로를 늘리면 채택하지 않는다.

새 차단 증명은 관측된 폐쇄 경계가 모든 목표 가설을 입구와 분리하는지 검사한다. 목표 내부 발판이 미관측이라는 이유만으로 증명을 금지하지 않되, 목표의 관측된 한 부분만 둘러싸인 경우 전체 목표를 차단으로 판정하지 않는다. 관측되지 않은 문·지붕·평가 범위 밖 대체 경로가 남으면 미확인이다. 바닥 증거가 없다는 이유만으로 차단하지 않는다. 기존 명령 호환을 위해 두 실험 모두 기본값은 꺼져 있다.

## 사전 실패와 한계

4초 연결 시험은 끝까지 연결됐지만 새 충돌 1건과 새 무효 경로 1건이 발생했다. 충돌 후보는 기존 frontier였고, 무효 경로의 첫 충돌 위치는 관측 지도에서 FREE였다. 이 결과를 성공으로 세거나 제외하지 않는다. 센서·지도 오류와 관측 가치의 효과를 구분한다.

별도 수직 시야 진단에서는 지도상 위쪽 이득이 큰 동일 후보에서 기존 상향각 +0.17rad와 +1.17rad를 비교했다. 실제 상층 자유 공간 관측은 모두 0이었다. 넓게 위를 보는 조건은 기하학적으로 유효한 깊이도 0이었다. 이는 **비행하지 않은 후보 시점의 사후 센서 진단**이고, 임무 성능에 포함하지 않는다. 짐벌 범위 확대를 개선으로 채택하지 않는다.

고정된 한 잠재 경로, 타일에 따른 구간 분할, 미관측 가림 근사, 범주형 몸 공간 증거는 여전히 한계다. 마지막 경로의 유효성을 별도 형상에서 검증하는 이유다. 어떤 조건에서도 기준 형상에 맞춰 관측 지도나 경로의 발 높이를 보정하지 않는다.
