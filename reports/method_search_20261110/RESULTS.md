# 사람 진입 관측 방법 탐색: 종료 시점 결과

## 요약

사람 진입 경로를 우선하는 관측 배정이 현재의 가상 화재 건물과 개발 사례에서 미관측량 우선보다 확실히 낫다는 결과는 얻지 못했다. 국소 경로 과제, 관측 높이 제한, 관측 위치 이격, 경로 비용 재정렬, 표면 융합을 조사했다. 가장 최근의 보수적 `completion_opportunity_v1`은 무효 안내를 만들지 않았지만 유효 경로나 올바른 차단도 추가로 확인하지 못했다.

이 문서는 **실제로 종료된 실행**만 요약한다. 중단된 초기 `opportunity32/` 출력은 결과에 사용하지 않았고, 동일 부모 체크포인트에서 새 경로 `opportunity32_completed/`로 8개 분기를 끝까지 다시 실행했다.

## 공통 조건과 평가

- 4대 드론, perfect odometry, 4 Hz, 320×180 깊이 샘플 격자, 180초 부모 상태에서 32초 연장.
- D455 공개 사양을 참고한 낙관적 가상 깊이 모델과 clean/strong 통제 저하. 실제 D455·실화재 연기 성능 재현이 아니다.
- 목표의 기하학적 참 도달 여부는 고정된 참 형상에서 발판·걸음·몸 폭/높이·충돌을 포함해 검증했다.
- `유효 경로`는 시스템이 제시한 순서 있는 경로가 참 형상에서도 통과 가능한 경우다. 참 지도에서 더 좋은 우회로를 다시 찾아 대체하지 않았다.
- 개발 장면 0/1/4/8, seed 0, clean/strong만 사용했으므로 일반화 성능을 주장하지 않는다.

## 방법 탐색 결과

| 실험 | 실제 실행 범위 | 관찰 | 결론 |
|---|---|---|---|
| 낮은 관측 고도 | school scene 1, clean, 96초 | unknown 고도 기본값 2개 유효 경로, entry 기본/저고도 각 1개 | 저고도만으로 개선되지 않음 |
| 관측 위치 이격 | 같은 사례, 96초 | unknown·entry 모두 유효 경로 1개 | 벽/미관측 경계에서 멀어지는 규칙을 채택하지 않음 |
| 국소 경로 보완 v5 | 8개 212초 짝지은 분기 | entry v4와 같은 유효 경로 11/70, 무효 경로 2/13 발생 | 채택하지 않음 |
| 경로 비용 재정렬 | 완료 지도 17개 재평가 | precision의 유효 경로 10→8, 무효 0→2 | 채택하지 않음 |
| 관측 표면 TSDF 재구성 | school 고정 궤적 재생 | noisy 재생은 1→2 유효 경로, ideal 재생은 2→2 | 오프라인 지도 표현의 신호이나 폐루프 배정에 미연결 |

상층 목표는 이상 깊이 재생에서도 유효 경로가 0개여서, 단순 깊이 잡음만이 병목은 아니었다. 지도 내 진단에서는 body-space 미확인이 많고, 관측 지도에서 자유로 표시된 위치가 참 형상 충돌이었던 사례도 확인됐다. 따라서 높은 경로 점수만으로는 경로 안내의 신뢰성을 보장하지 못한다.

## `completion_opportunity_v1` 분기

이 정책은 현재 확인된 입구 연결 성분에서 출발한 잠재 경로에 대해, 후보 한 개가 경로의 **모든** 미확인 몸 공간·발판 증거를 함께 볼 수 있을 때만 entry 값으로 개입한다. 직렬 구간의 일부만 보는 후보는 목표 완성 이득을 얻지 않는다. 실제 비행 가능한 후보가 없거나 완성 이득이 없으면 unknown 점수로 되돌아간다. 이 점수는 지도나 사람 그래프를 바꾸지 않는 선택용 약속(visibility coverage)이며, 실제 판정은 관측 후 기존 파이프라인이 수행한다.

### 212초 최종 집계

| 항목 | 값 |
|---|---:|
| 유효 경로 확인 | 10 / 70 (14.3%) |
| 올바른 차단 확인 | 0 / 74 (0.0%) |
| 무효 안내 | 0 / 10 (0.0%) |
| 미확인 목표 | 134 / 144 |
| 판정률 | 10 / 144 (6.9%) |
| 180→212초 새 유효 경로 | 0 |
| 180→212초 새 올바른 차단 | 0 |
| 180→212초 새 무효 안내 | 0 |
| 추가 촬영 / 이동거리 | 3,328 / 198.09 m |
| 새 실패 드론 / 충돌 | 4 / 4 |

47회의 게이트 판단 중 양의 완성 기회는 1회뿐이었고, 최종 목표 판정을 바꾸지 못했다. 그 외에는 정책이 탐색 대체 규칙을 사용했다. 같은 부모에서 끝낸 `unknown_common`은 10/70 유효·전체목표영역 기준 0/74 올바른 차단·0/10 무효였고, 기존 entry v4는 11/70·0/74·0/11이었다. 따라서 이 보수적 게이트는 안전하지만 이 개발 비교에서 entry 우위를 만들지 못했다.

사례별 최종 지도·경로·선택은 `results/method_search_20261110/opportunity32_completed/scene{0,1,4,8}_{clean,strong}/`에 있다. 각 폴더의 `summary.json`, `target_paths.csv`, `assignments.jsonl`, `events.csv`, `frames/`, `maps/`가 재생·검증 입력이다.

## 논문에 쓸 수 있는 결론과 쓰면 안 되는 결론

쓸 수 있는 결론:

- 명시한 센서·시간·사람 모델에서 목표별 경로 검증을 포함한 폐루프 비교가 가능하다.
- 현재 설계에서는 unknown과 entry의 최종 차이가 작고, entry의 일반적 우월성은 확인되지 않았다.
- 차단 증명은 목표 영역 전체를 대상으로 해야 하며, 관측된 목표의 일부만 막혔다고 차단으로 결론내리면 안 된다.

쓰면 안 되는 결론:

- 실제 화재나 실제 D455에서 성능을 검증했다는 주장.
- 현재 4개 개발 장면·seed 0의 작은 차이로 일반적인 우월성을 주장하는 것.
- TSDF 고정 궤적 재생의 1개 경로 증분을 배정 정책의 성능 향상으로 해석하는 것.
