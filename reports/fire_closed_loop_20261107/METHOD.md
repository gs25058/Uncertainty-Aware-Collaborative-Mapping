# 확대 화재 복층 건물의 4대 드론 폐루프 비교

비교 명칭은 **공통 다중 드론 탐색 파이프라인에서 관측 가치 함수 비교**다. 사용자가 확인한 10개 확대 화재 건물의 고체 형상을 그대로 사용한다. 드론의 관측으로 만든 공유 지도에서 `unknown`과 `entry`의 관측 가치만 바꾼다. 건물의 실제 도달 정답과 제시 경로는 시뮬레이터/평가기에서 따로 검사한다.

## 실행 전에 고정한 조건

[설정](../../configs/fire_closed_loop_20261107.json)의 동결본은 `results/fire_closed_loop_20261107/main/fixed_config.json`이다. 장면 0–9, 실행 seed 0, clean/strong, unknown/entry의 **40회**이며 각 회는 드론 4대, 임무 180초다. 뒤 드론의 진입 시각은 2/4/6초이고 대기 시간도 임무에 포함한다. 센서는 이동 중에도 4Hz로 촬영한다. 시뮬레이션 tick 0.25초, 배정 4초, 평가 8초와 마지막 180초, 지도 스냅샷 20초다.

위치는 `perfect_odometry`, 통신은 즉시 공유, 운동은 계획 궤적의 운동학적 정확 추종이다. 계산 시간과 시뮬레이션 시간을 구분하며 실시간 구동을 주장하지 않는다. 충돌한 드론은 마지막 안전 위치에 고정하고 다른 드론을 계속 운영한다. 실패 실행을 분모에서 제외하지 않는다.

## 건물과 평가 구역

2층 5개/3층 5개(총 25개 층)의 apartment, school, office, hotel, clinic, retail, workshop, dormitory, duplex, library다. 생성 인덱스 0–9와 화재 규모 3을 고정했다. 벽·문·창·계단·잔해·바닥 구멍·가구는 `results/fire_buildings_large_fire_20261107`의 형상과 같다. 화염은 고체 장애물이 아니다. 열·가스·구조 안정성이나 붕괴의 시간 변화는 평가하지 않는다.

기존 표시용 목표 중심이 침대/책상 안에 있거나 입구 중심이 내부 칸막이에 걸린 문제를 기준 검사에서 발견했다. 정책 실행 전에 입구를 실제 1.85m 개구부 안의 폭 1.2m 영역으로, 목표를 각 방 바닥의 내부 영역(경계 5cm 제외)으로 고정했다. 원본 메시와 이전 산출물은 보존했다. 모든 방법에 같은 구역을 사용하며 벽/층을 가로지르는 좌표 스냅은 없다. 각 층 목표의 발 높이 범위는 바닥 기준 −0.10~+0.25m다.

총 **218개 목표 = 도달 가능 112 + 도달 불가 106**이다. 소매점 장면은 도달 불가 목표가 0개이므로 해당 장면의 차단율/균형 점수는 N/A이며 실행을 제외하지 않는다. 입구와 목표 구역이 겹치는 경우 짧거나 한 점인 경로도 현재 목표 정의에서 허용된다. 최종 상세 표는 경로 길이 및 1m 초과 유효 경로를 추가로 구분한다. 이 보조 구분으로 주 지표의 분모를 바꾸지 않는다.

정답은 `fire_reference.py`가 완전한 삼각 메시의 위쪽 면에서 10cm 간격으로 지지를 샘플하고, 사람 몸체와 고체의 충돌 및 18cm 걸음 높이·대각선 제한을 검사해 만든다. 도달 가능 경로 112개는 별도 `ReferenceValidator`로 검사했다. 최종 정답/영역은 `results/fire_closed_loop_20261107/evaluation_cases.json`, `reference_final/scene{0..9}.json`에 있다. 정책 결과를 보고 정답을 변경하지 않는다. 도달 불가는 이 고정 간격의 기하 로드맵에 대한 정답이며, 연속 공간의 모든 미세한 우회 경로가 없다는 수학적 증명은 아니다. 제시 경로와 정답이 모순되는 경우를 사후 감사에서 별도로 기록한다. 추가 원인 검사에서 모든 3층 건물의 2층 계단 시작점에 하부 층계참이 누락되어 복도 바닥과 첫 단 사이에 27cm 빈틈이 있음을 확인했다. 의도하지 않은 장면 생성 결함이다. 따라서 이번 동결 장면의 3층 차단을 관측 정책의 성공/실패로 해석하면 안 된다. 기준 메시의 5개 건물·양쪽 10개 계단 광선 검사는 `results/fire_closed_loop_20261107/diagnostics/third_floor_landing_probes.json`에 있다. 그 밖의 가구/잔해 배치도 입구 연결에 영향을 준다. 빈 방이라는 이유로 도달 가능이라고 간주하지 않는다. 층별 기준 구성은 1층 R60/B26, 2층 R52/B34, 3층 R0/B46이다. 따라서 이번 장면들은 2층까지의 유효 경로와 상층 차단 판정을 시험하지만, 3층에 실제 도달 가능한 경로를 확인하는 능력은 검증하지 못한다. `data/reference_targets_compact.csv`에 이 구성을 공개한다.

사전 정보는 건물 경계, 입구 대기 공간, 모든 층의 익명 목표 영역이다. 방의 목표 위치를 제공하는 임무를 가정한다. 내부 벽·문 상태·계단 목록·화재 소스·도달 정답은 계획기 입력이 아니다.

## 관측 모델과 확대 화재의 연결

모델 명칭: **RealSense D455급의 공개 사양을 참고한 낙관적 깊이 관측 모델과 통제된 관측 저하 조건**. 이번 백엔드는 `depth_error_model`이다. 영상 생성과 SGBM은 생략하고 실제 카메라/짐벌 포즈에서 메시 첫 표면을 raycasting한다. 오른쪽 카메라의 가시성과 드론 가림도 검사한다. 지도에는 오염된 optical-Z 깊이를 추정 포즈로 적분한다. 역투영은 Z, 연기 적분은 광선 길이를 쓴다. 공개 배열은 Z, 설정과 관측값으로 계산한 sigma, valid, 포즈, 시간, 동료 위치뿐이다. 참 깊이/오차/이상치 마스크/T는 정책에 전달하지 않는다.

| 항목 | 이번 값/성격 |
|---|---|
| 양안 간격, 시야각 | 0.095m, 87°×58°; 기존 공개 사양 참고 프로필 |
| 유효 Z 범위 | 0.6–6m; 이번 실험 제한 |
| 샘플 격자/적분 속도 | 320×180, 4Hz; 좋은 센서의 성긴 깊이 출력 근사 |
| 명목 모드 정보 | 프로필의 1280×720/30Hz와 다른 모드의 최대 90Hz를 구분; 이번 실행 속도가 아님 |
| 정상 σ_z | 0.002+0.001z² m; 제조사 보장 분포가 아닌 고정 실험 설정 |
| 정상 누락/큰 이상치 | 기하학적 유효 픽셀 중 0.5%/0.05%, 이상치 ±5–20cm |
| 상관성 | 기체 고정 편향 σ=1mm, 공간 격자 0.15m, 시간 격자 0.75s + 독립 잡음 |
| 경계/입사각 | 기존 프로필의 완만한 증가(σ 최대 1.5배, 누락 +0.02) |
| strong 저하 | k=3, a=0.20, q=0.005; 사전 고정한 설정 |

추가 구현 `fire_smoke.py`는 확대 화재의 **75개 소스**를 센서 저하에 연결한다. 0.2m 격자에서 고체 마스크를 둔 6방향 확산을 160회 수행한다(확산 0.12, 감쇠 0.035, 소스 이득 0.08). 방 안의 Gaussian 소스와 천장 쪽 가중치로 시작하는 무차원 정상장을 사용한다. 모든 드론이 같은 장과 완만한 시간 변조를 공유한다. 이것은 CFD나 실제 농도/열방출률 모델이 아니다. 고체 셀의 밀도는 0이다.

각 광선의 16개 중간점으로 τ=0.4×광선길이×평균밀도, T=exp(−τ)를 계산한다. 기존 식 `σ=σ_clean[1+k(1−T)]`, `p_drop=p_clean+(1−p_clean)a(1−T)`, `p_outlier=p_clean+q(1−T)`를 쓴다. clean에서는 k=a=q=0이고 좋은 센서의 정상 오차는 유지한다. 범위 밖 깊이는 invalid이며 빈 공간 ray를 만들지 않는다. 소스/밀도는 관측 생성용 비공개 정보다. 이전 viewer의 표시용 연기 입자를 센서 측정값으로 간주하지 않는다.

공식 자료를 참고해 만든 기존 프로필과 설정의 구분은 [깊이 모델 문서](../depth_model_20261106/SENSOR_MODEL.md), [프로필](../../configs/sensors/d455_inspired_optimistic.json)에 있다. 이번 결과는 실제 D455·실화재·SGBM 재현 성능이 아니다.

## 공통 지도·사람 판정·이동

10cm 점유지도와 관측 표면 지지층을 쓴다. 지지 확인은 **서로 다른 촬영 2회 이상, evidence≥1.2, 높이 표준편차≤5cm**다. 확인 그래프에서 미관측 발판을 틈 규칙으로 넘지 않는다. 사람 높이 stand/stoop/crawl=1.90/1.40/0.90m, 폭 normal/sideways=0.70/0.45m, 걸음 높이 0.18m, 발 접촉 오프셋 0.025m다. 이 사람 모델의 기하학적 도달만 평가한다.

복층 연결을 위해 관측 표면의 실제 XY/평균 Z/산포와 관측 endpoint 최대 높이를 보존한다. 발판이 걸친 부분 복셀의 바닥을 몸체 장애물로 오해하지 않되, 관측된 돌출 장애물과 미관측 몸 공간은 유지한다. 자세한 발생 조건과 변경은 [FIXES](FIXES.md)에 있다. 두 정책에 같은 수정과 같은 사람 크기를 적용한다.

`passable`은 확인 그래프의 실제 경로, `unverified`는 증거 부족, `blocked`는 미관측 연결과 높이 조건을 완화한 그래프에서도 관측된 포위가 확인되는 경우다. 경로가 없다는 이유만으로 blocked로 바꾸지 않는다. 완전한 장면에서도 보수적 차단 증명은 106개 중 100개를 확인하고 6개를 미확인으로 남겼다.

공통 후보는 현재 관측 FREE에서만 생성하며 observed_free 높이를 샘플한다. 최대 24개, 재관측 최대 10개, 구간 중요도 검사 최대 6개, 관측 가능성 표본 최대 24개로 같은 계산 예산을 쓴다. `unknown`은 예상 미관측 복셀의 추가 이득, `entry`는 구간을 열거나 닫을 때 목표 도달이 달라지는 수와 발판/몸 공간 가시성의 최솟값을 사용한다. 같은 목표 중복을 제한하고 필요한 추가 표면 증거를 반영한다. 값이 없으면 entry도 unknown으로 대체하며 시간과 선택을 기록한다. 가치 함수 가중치(0.8/0.2), 시간 비용(0.008), unknown 정규화(1500)는 이전과 같다.

최종 비용은 실제 A* 경로와 FUEL Polynomial 시간화의 이동/회전/대기를 반영한다. 기체 반경 0.14m+여유 0.04m, 속도 1m/s, 가속도 1.5m/s², yaw 90°/s, pitch 60°/s, 예약 0.1초, 최대 대기 8초다. ROS/RACER 전체 재현은 아니다. 외부 코드 커밋과 빌드 범위는 [기존 EXTERNAL_AUDIT](../closed_loop_20261105/EXTERNAL_AUDIT.md)에 고정돼 있다.

## 지표와 출력

최종 180초 상태가 주 결과다. 유효 경로 확인율=기준 도달 가능 중 실제 제시 경로가 메시에서 유효한 수/112, 올바른 차단율=기준 차단 중 blocked 수/106, 균형 점수=두 비율 평균이다(조건/정책당 10장면 합산). 잘못 안내한 비율=무효/(유효+무효 검증 완료 경로); 분모 0은 N/A다. 제안/검증 불가/미확인/판정률·잘못된 차단도 별도로 기록한다. 경로는 시작/목표/층/지지/걸음/경로 사이 몸체/자세 변화를 검사하며 평가기가 다른 우회 경로로 대체하지 않는다.

과거 면적 지표의 코드는 보존했다. 이번 주 지표는 복층 목표·제시 경로다. 층을 XY로 겹쳐 이전 단층 IoU로 보고하지 않는다. 시간별 평가는 8초 및 마지막 시각의 표본이며 연속 시간의 모든 일시적 판정을 기록했다고 주장하지 않는다.

`frames/*.npz`, `frames.csv`, `trajectories.csv`, `maps/*.npz`, `replay_manifest.json`이 실제 관측 순서와 지도 재생 입력이다. 후보·점수·배정·cut 가정은 JSONL, 목표별 경로·첫 실패는 CSV, 충돌/정지/대기는 events.csv에 남는다. 원본/실패 기록은 보존하며 결과 경로는 별도다.
