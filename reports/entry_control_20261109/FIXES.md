# 실행 관리 오류와 마무리 범위

새 조종 배치의72조건 중71조건이180초까지 완료됐다. `guarded_unknown/scene0_seed0_strong_unknown`은 촬영·체크포인트가 하나도 없는 실행 시작 전 오류다. 사용자 요청에 따라 새로 시작하지 않았다. 시뮬레이션 중 충돌한 드론이나 미확인 목표는 이 미실행 조건과 구분하며 모두 결과에 남겼다.

동시 실행 수를 세는 `Path('/proc').glob('[0-9]*/cmdline')` 내부에서 프로세스가 종료되면 `ProcessLookupError`가 발생할 수 있었다. 파일 읽기만 감싼 예외 처리 밖에서 glob이 먼저 실패해 관리기가 종료됐고, 이미 제출된 나머지 실행은 계속 완료됐다. 오래된 running 상태를 실제 완료 파일과 대조해71완료·1미시작으로 복원했다.

프로세스 디렉터리를 먼저 나열하고 cmdline 읽기를 예외 처리 안으로 옮겼다. Future 예외도 조건별 실패 기록으로 수집하도록 바꿔, 다른 결과가 사라지거나 running으로 남지 않게 했다. 이 수정은 관리 코드이며 실제 비행·센서·지도·사람 판정의 수학 소스를 바꾸지 않았다.

이전에 관리기를 재시작할 때 중복 배치 잠금이 거절된 일도 있었다. 이미 실행 중인 배치를 기다리도록 수정했으며 기존 관측/기체 상태를 재설정하지 않았다. 실행 관리 이력과 원시 오류는 서버 `results/entry_control_20261109/`에 보존한다.

전체 모형 순위는 공통8사례가 모두 있는 조건에서만 고른다. guarded의 가치 비교는 공통 완료7사례끼리 계산하고, 빠진 사례를 기존 제어의 unknown으로 대신 채우지 않는다. 원래 계획의 결합24회·조종 검증80회와 주 실험의 새 시드100회는 미실행이다.

현재 통합 결과·실제 분모·미시작 CSV는 [마무리 보고](../entry_optimization_20261109/current/RESULTS.md)에 있다. 핵심39검사와 깊이/장면 회귀21검사, 총60개가 통과했다. 저장 궤적·센서의 재생·실제 제시 경로의 독립 검증은 통합 감사에 별도로 기록한다.
